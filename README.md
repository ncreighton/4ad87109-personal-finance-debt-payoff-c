# Personal Finance Debt Payoff Calculator and Budget Coach Telegram Bot

A Telegram bot for personal finance coaching apps and fintech products helping users eliminate debt and build savings. Calculates debt snowball and avalanche payoff schedules based on entered balances and interest rates, tracks monthly budget categories with spending alerts, sends weekly net worth update reminders, provides motivational milestone celebrations when debts are paid off, and delivers personalized financial habit coaching tips based on the user spending patterns.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
